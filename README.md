# Leo Stack Services Portfolio Website

A modern, responsive portfolio website for Leo Stack Services, showcasing professional web development, e-commerce, mobile app development, and graphic design services.

## Features

- Responsive design that works on mobile, tablet, and desktop devices
- Modern and clean user interface
- Service showcase section
- Team member profiles
- Portfolio gallery
- Contact form
- Smooth scrolling navigation
- Mobile-friendly navigation menu

## Project Structure

```
portfolio-website/
├── css/
│   ├── style.css        # Main styles
│   └── responsive.css   # Responsive design styles
├── js/
│   └── main.js         # JavaScript functionality
├── images/             # Image assets
├── index.html         # Main HTML file
└── README.md         # Project documentation
```

## Setup Instructions

1. Clone or download this repository
2. Ensure all files maintain their directory structure
3. Add your images to the `images` directory
4. Customize the content in `index.html` as needed
5. Update the portfolio items in `main.js`
6. Deploy to your web hosting service

## Required Assets

- Team member photos (recommended size: 400x400px)
- Portfolio images (recommended size: 800x600px)
- Logo (if available)
- Hero background image (recommended size: 1920x1080px)

## Customization

### Colors
The color scheme can be modified in the `css/style.css` file by updating the CSS variables in the `:root` selector:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --text-color: #1f2937;
    --light-text: #6b7280;
    --background: #ffffff;
    --section-bg: #f3f4f6;
}
```

### Content
Update the content in `index.html` to match your specific services, team information, and contact details.

### Portfolio
Modify the portfolio items in `main.js` by updating the `portfolioItems` array.
